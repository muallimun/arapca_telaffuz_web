Yerel sunucuyu (localhost) başlatmak için sadece iki adımı takip etmen yeterli. 

Projenin kurulu olduğu klasörde terminali (PowerShell veya VS Code terminali) aç ve şu komutları çalıştır:

### 1. Adım: Proje dizinine git
Eğer terminal şu an projenin içinde değilse, önce proje klasörüne gitmelisin. (Senin bilgisayarındaki yol şuydu):
```powershell
cd E:\Muallimun.Net\arapca_diyalog_uygulamasi\arapca-platform
```

### 2. Adım: Sunucuyu başlat
Proje dizinine geldikten sonra şu komutu çalıştır:
```powershell
npm run dev
```

### 3. Adım: Tarayıcıda aç
Terminalde birkaç saniye içinde şöyle bir çıktı göreceksin:
```text
▲ Next.js 16.4.3 (Turbopack)
- Local:         http://localhost:3000
```
Bu yazıyı gördüğünde tarayıcını aç ve adres çubuğuna **``** yazarak uygulamaya girebilirsin. http://localhost:3000

*(Eğer terminalde 3000 portunun dolu olduğuna dair bir uyarı alırsan, sana `http://localhost:3001` adresini verecektir, o adrese gitmen yeterli.)*

Sunucuyu kapatmak istediğinde ise terminaldeyken **`Ctrl + C`** tuşlarına basıp `Y` (veya `Evet`) diyerek onaylayabilirsin. 

Sunucuyu başlatıp yeni eklediğimiz **Gölgeleme (Mikrofon)** özelliğini test edebilirsin!
